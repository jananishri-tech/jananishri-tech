A hybrid monitoring architecture concept for scenarios where conventional cellular connectivity is unreliable or unavailable. Combines ESP32-based sensor nodes, ultrasonic and soil-moisture sensing, fire/heat detection, LoRa communication, gateway infrastructure, Firebase, and a possible satellite-backhaul layer.

`ESP32` `LoRa` `Firebase` `Sensor Networks` — *Concept/architecture stage; not confirmed as fully deployed.*
